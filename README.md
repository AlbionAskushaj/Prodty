# Prodty

A productivity app for people who cannot follow a schedule. You tell a lantern-headed wizard what is on your mind and he sorts it onto trees in a forest.

- `docs/handoff.md` is the place to start: what is built, what is checked, and what comes next.
- `docs/plan.md` has everything decided, and the build stages.
- `app/` is the web app. See `app/README.md` to run it.
- `assets/` holds the generated art and music.
- `tools/` holds scripts that prepare art, build the preview page, and check the app in a browser.
